# 现代编程书系 · AI 重构版

> 一套由 AI 完整重写的 Windows 编程与脚本教材、API 手册。
> 沿用经典教材的知识脉络，剔除已废弃的技术，补上 2026 年的现代实践。

**版本：2026-08-14**　·　**许可：CC BY-NC-SA 4.0**

---

## 这是什么

经典编程书籍有一个共同的困境：**知识结构是好的，技术细节却在过时。**

Petzold 的《Windows 程序设计》第 5 版停在 2000 年，仍在讲 16 位遗留；侯捷的《深入浅出 MFC》成书于 VC++ 5.0 时代；孙鑫的《VC++ 深入详解》基于 VC6。它们讲透了原理，但书中大量 API、工具链、编码实践，今天照做就是错的。

**这套书解决的正是这个问题**：由 AI 沿着经典教材的知识脉络，**逐章重新撰写**——保留那些经得起时间检验的原理与讲法，删掉过时内容，并在每一处已变化的地方标注现代替代方案。

不是摘录，不是翻译，不是电子版。**全部文字、代码示例与插图均为重新创作。**

## 设计原则

**① 讲清「为什么」，而不只是「怎么做」**

每个机制都从问题出发：先问「这里要解决什么」，再讲原理、打比方、点出设计动机。理解了动机，API 细节自然记得住。

**② 四色现代标注贯穿全书**

凡涉及技术演进之处，逐一标注：仍适用 / 已过时 / 已废弃 / 现代替代方案。你能清楚知道哪些该学、哪些该跳过、今天该用什么。

**③ 原创图解**

关键机制配手绘 SVG 示意图——消息流动、类继承体系、双缓冲原理、DLL 链接方式等，矢量绘制，任意缩放清晰。

**④ 统一的阅读体验**

深浅色主题切换、目录折叠、阅读位置实时高亮、侧栏宽度可拖拽。纯 HTML 单文件，零依赖，无需联网或构建。
