## 这是什么

经典编程书籍有一个共同的困境：**知识结构是好的，技术细节却在过时。**

Petzold 的《Windows 程序设计》第 5 版停在 2000 年，仍在讲 16 位遗留；侯捷的《深入浅出 MFC》成书于 VC++ 5.0 时代；孙鑫的《VC++ 深入详解》基于 VC6。它们讲透了原理，但书中大量 API、工具链、编码实践，今天照做就是错的。

**这套书解决的正是这个问题**：由 AI 沿着经典教材的知识脉络，**逐章重新撰写**——保留那些经得起时间检验的原理与讲法，删掉过时内容，并在每一处已变化的地方标注现代替代方案。

不是摘录，不是翻译，不是电子版。**全部文字、代码示例与插图均为重新创作。**

## 设计原则

**① 讲清「为什么」，而不只是「怎么做」**

每个机制都从问题出发：先问「这里要解决什么」，再讲原理、点出设计动机。理解了动机，API 细节自然记得住。

**罗列不是讲解**——这是全书系的硬标准：代码与表格只是载体，每个重点知识点都要有成段正文交代四件事：**本质**（为什么存在、为什么长成这样）、**逻辑**（怎么运作、与相邻机制怎么衔接）、**功能**（什么时候用、不解决什么）、**门道**（边界、陷阱、失效条件与判据）。自查办法很简单：遮住全部代码与表格，剩下的正文能不能独立把这件事讲明白。

**② 四色现代标注贯穿全书**

全库 5155 条提醒装在四种颜色的批注框里，颜色本身就是分类：🔴 **陷阱 / 事故**（不知道会出事）、🟡 **历史包袱**（能用但别选）、🟢 **推荐 / 正解**（该这么写）、🔵 **现代替代**（今天该用什么）。你能清楚知道哪些该学、哪些该跳过、哪些一碰就出事。

**③ 原创图解**

同一本书有两个深度：**薄**只留主干，适合通读与复习；**厚**展开全部深入层、边界条件与踩坑记录。右上角一个开关随时切换，阅读位置不丢。

**⑤ 统一的阅读体验**

深浅色主题切换、目录折叠、阅读位置实时高亮、侧栏宽度可拖拽。纯 HTML 单文件，零依赖，无需联网或构建；上百万像素高的长文也能秒开——每一块的占位高度都是在真实浏览器里量出来、再回写进文件的。

## 开始阅读

```bash
git clone https://github.com/rbldy1989/learning-book.git
cd learning-book
# 用浏览器打开 index.html
```

`index.html` 是书架首页，按九个方向分组，每本书配封面、简介与规模数字（章节数、字数、图表与代码段数量全部从成品实算），点击直达。

每本书的第一节是**导读**：这个领域是什么、有哪些经典资料、本书借鉴了它们的什么、需要什么基础、读完能得到什么——一屏半读完，再决定要不要往下读。

也可直接打开任一本书的 HTML 文件独立阅读——每本都是自包含的单文件。
