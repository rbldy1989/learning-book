# 现代编程书系 · AI 重构版

> 一套由 AI 完整重写的编程教材、API 速查手册与开源项目源码精读：Windows 原生开发、Linux 系统编程、C/C++ 标准库、Web 前端、脚本与工程协作。
> 沿用经典教材的知识脉络，剔除已废弃的技术，补上 2026 年的现代实践。

**版本：2026-08-24**　·　**共 28 本**　·　**许可：CC BY-NC-SA 4.0**

---

## 这是什么

经典编程书籍有一个共同的困境：**知识结构是好的，技术细节却在过时。**

Petzold 的《Windows 程序设计》第 5 版停在 2000 年，仍在讲 16 位遗留；侯捷的《深入浅出 MFC》成书于 VC++ 5.0 时代；孙鑫的《VC++ 深入详解》基于 VC6。它们讲透了原理，但书中大量 API、工具链、编码实践，今天照做就是错的。

**这套书解决的正是这个问题**：由 AI 沿着经典教材的知识脉络，**逐章重新撰写**——保留那些经得起时间检验的原理与讲法，删掉过时内容，并在每一处已变化的地方标注现代替代方案。

不是摘录，不是翻译，不是电子版。**全部文字、代码示例与插图均为重新创作。**

## 设计原则

**① 讲清「为什么」，而不只是「怎么做」**

每个机制都从问题出发：先问「这里要解决什么」，再讲原理、打比方、点出设计动机。理解了动机，API 细节自然记得住。每个知识点都按同一条标杆交付：讲清本质、放进大局、给出直觉、划出边界、能落到实战。

**② 四色现代标注贯穿全书**

全书 2040 条提醒装在四种颜色的批注框里，颜色本身就是分类：🔴 **陷阱 / 事故**（不知道会出事）、🟡 **历史包袱**（能用但别选）、🟢 **推荐 / 正解**（该这么写）、🔵 **现代替代**（今天该用什么）。你能清楚知道哪些该学、哪些该跳过、哪些一碰就出事。

**③ 原创图解**

关键机制配手绘 SVG 示意图——消息流动、类继承体系、双缓冲原理、DLL 链接方式、Git 对象图等，矢量绘制，任意缩放清晰。

**④ 薄／厚两种读法，一键切换**

同一本书有两个深度：**薄**只留主干，适合通读与复习；**厚**展开全部深入层、边界条件与踩坑记录。右上角一个开关随时切换，阅读位置不丢。

**⑤ 统一的阅读体验**

深浅色主题切换、目录折叠、阅读位置实时高亮、侧栏宽度可拖拽。纯 HTML 单文件，零依赖，无需联网或构建；上百万像素高的长文也能秒开——每一块的占位高度都是在真实浏览器里量出来后烘进文件的。
