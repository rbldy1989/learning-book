# Windows 编程学习笔记

一套原创的 Windows 原生编程教材与速查手册，全部为 HTML 单文件，开箱即读。

**版本：2026-08-14**

---

## 在线阅读

克隆或下载后，用浏览器打开 **`index.html`** 即可进入书架首页。

```bash
git clone https://github.com/rbldy1989/learning-book.git
cd learning-book
# 双击 index.html
```

---

## 内容

| 书目 | 规模 | 简介 |
|---|---|---|
| **Win32 程序设计 · 现代详解** | 18 章 · 172 节 | 从零讲透 Windows 原生编程：消息机制、GDI、控件、位图、多线程。**只讲现代 32/64 位**，去除已废弃内容，含环境搭建与高 DPI / 深色模式等现代补遗 |
| **深入浅出 MFC · 详解与现代批注** | 16 章 · 94 节 | 原创重讲 MFC 六大关键技术、Document/View 架构与消息映射机制 |
| **VC++ 深入详解 · 详解与现代批注** | 20 章 · 198 节 | Windows 机制、MFC 剖析、绘图、网络、多线程、IPC、DLL、COM 等实战主题 |
| **Windows API 手册** | 9 章 · 172 个函数 | kernel32 / user32 / gdi32 三大 DLL 分类速查，每个函数配原型、参数表、返回值与最小示例；含 `WM_` / `WS_` / `CS_` 大速查表 |
| **C 标准库 API 手册** | 8 分类 · 99 个函数 | 按头文件分类，二级标题即函数名；含经典陷阱提醒与安全版 `_s` 对照 |

---

## 特点

- **全部原创撰写** —— 非任何书籍的电子版或摘录
- **现代技术批注** —— 对已过时 / 已废弃的 API 与做法给出 2026 年的替代方案
- **统一的阅读体验** —— 深浅色切换、目录折叠、阅读位置高亮、侧栏宽度可拖拽
- **原创示意图** —— 关键机制配手绘 SVG 图解，矢量清晰
- **零依赖** —— 纯 HTML 单文件，无需联网、无需构建工具
